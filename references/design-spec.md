# 从参考图到实现约束

当任务包含复杂布局、多页、已有视觉参考或容易发生还原偏差时读取。记录的目的，是让后续实现和截图比较有依据；按任务删减字段，不要求每次生成一份长文档。

## 先决定哪些内容不能变

| 来源 | 如何使用 |
| --- | --- |
| 用户要求与明确指定的原始参考 | 确定内容、范围、品牌、技术栈和交付形式；精确复刻时也是最终对照依据 |
| 现有项目 | 复用组件、设计变量、字体、素材及已经正常工作的路径 |
| 选定的生成图 | 确定本次视觉实现的构图和细节；不能覆盖以上约束 |
| 实现补充 | 为窄屏、键盘、长内容和状态补全作合理决定，并与图中直接可见的事实区分 |

若两项明确要求相互冲突且无法从上下文解决，先提出具体冲突；不要偷偷选择更容易实现的一项。

## 生成提示词示例

示例用于说明约束写法，不是默认风格。替换产品、文案、配色与尺寸，保留用户明确指定的内容。

### 新建：先写任务和内容，再写视觉

```text
生成一张可供实现的中文专注计时器网页高保真参考。
目标：让用户快速开始一次专注；桌面横向界面，画面比例约 4:3。
结构：简洁顶栏；左侧是主要计时器，显示 25:00、“开始专注”和重置操作；
右侧是今日任务列表，显示任务标题、时长和选中状态；下方保留今日统计。
视觉：暖白背景、深墨色文字、低饱和绿色强调色、清楚的排版层级与留白。
用少量准确中文展示主要标签，主操作最醒目。
正视平面 UI 截图，边界完整；不加设备外壳、浏览器工具栏、透视或水印。
```

### 已有参考：分清保持与修改

```text
输入图片是必须遵循的界面参考，先保留其主要布局与视觉比例。
保留：现有顶栏、品牌色、字体层级、左右分栏和组件形态。
修改：为右侧任务列表增加一个与现有风格一致的空状态及“添加任务”按钮。
只展示目标区域与必要上下文，不重新设计整页，不新增侧栏、品牌或功能模块。
输出清晰、正视、平面的 UI 参考图。
```

编辑本地图片前先查看原图；调用时用实际工具支持的引用方式，不在提示词里虚构已附图。要求精确复刻时，生成图若偏离原始参考，应修正偏差，最终仍按原始参考核对。

## 设计记录模板

```text
选定参考：实际可用的路径或结果标识；已查看。
交付范围：哪些页面、组件或状态；主要操作路径。
平台与输入：网页/原生/小程序/桌面/游戏等；触控、键鼠或控制器。
参考画幅：已知尺寸或宽高比；实现使用的目标视口。
必须保留：最能识别这一设计的构图、品牌和视觉重点。
区域关系：主要内容宽度、分栏比例、首屏重点、对齐与留白。
视觉变量：背景/表面/文字/强调/边框；字体层级；间距、圆角、阴影。
素材：哪些是正式资源、哪些只是参考；实际引用位置。
实现补充：窄屏重排、长文本、键盘和主要交互状态。
允许调整：图片错字、示意数值、可读性及可用性问题；说明原因。
待确认：确实影响方向或验收的缺项；其余注明合理假设。
```

数值可以来自原项目、图像取样或合理估计。注明来源；不能从一张普通截图精确推断所有间距和字体。先使用少量有明确角色的变量，让同类组件保持一致，避免给每个元素单独“猜一个数”。

## 处理没有画出来的内容

- **窄屏：** 按任务重要性安排顺序；分栏可堆叠，次要导航可折叠，表格可在自身区域滚动。不要把桌面图整体缩小，也不要用全局裁切掩盖溢出。
- **长内容：** 优先自然换行和合理增长；确需截断时保留获取完整内容的方式。用实际语言检查，尤其注意中文按钮、数字和混合文本。
- **组件状态：** 从用户操作推导需要的状态。例如提交表单需要校验与反馈；静态展示不需要为了“完整”伪造提交接口。
- **失败后的出路：** 将保存、重试与离开当前页面分别判断。位置保存或草稿写入失败时，说明未保存的后果，并保留适合任务的返回或放弃路径；持续重试不能成为离开的唯一条件。涉及提交中的不可逆操作时，依据真实状态决定可取消范围。
- **切换后的连续性：** 按操作含义决定滚动、选中项和焦点。阅读换篇通常应从新内容开头读；表格筛选或编辑返回则可能需要保留位置。区分鼠标与键盘操作，避免重绘控件后焦点掉到页面根节点，也不对所有操作一律抢焦点或回到顶部。
- **平台行为：** 根据目标处理适用的安全区域、软键盘、返回行为、系统主题、窗口变化或控制器焦点；原生控件与网页控件各用对应实现，不默认把所有任务变成 HTML 页面。
- **画布与控件：** 游戏场景或画布可以按比例缩放；操作文字、按键提示和命中区域还要在最小目标窗口中单独检查。必要时独立布局或重排，不能仅因整张画面放得下就认为控件仍然清楚。
- **素材：** 将照片、插画等可独立复用的图像与真实控件分开。模型画出的按钮和文字不是交互组件；不能靠透明点击区域覆盖整张图实现界面。
- **数据：** 图片中的数字、图表和业务结论没有事实效力。实际数据以任务来源为准，演示数据明确标识。
