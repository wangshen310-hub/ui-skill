# 2026-10-20 腾讯云验证

这是首轮记录，使用技能版本 `a5eb2ab`。后续[独立评审](reviews/r01-blind.md)发现了原运行检查未覆盖的问题，[复核数据](artifacts/r01-recheck.json)保留了复现结果；本轮通过不能代表不存在其他缺陷。

按修改后的技能做了两个隔离样例：中文阅读网页、原生游戏暂停菜单。参考图生成后先查看、记录设计，再写界面；构建、运行、交互检查和截图均在腾讯云执行。本地只编辑文件和查看下载的截图。

环境：OpenCloudOS 9.6，Node.js 20.20.2，Python 3.11.6。网页使用 Vite 8.3.4、Chrome 和 Patchright 1.58.2；游戏使用 Pygame 2.6.1，在 Xvfb 下运行实际 SDL 窗口。

## 复现位置与范围

隔离样例和测试脚本留在腾讯云的 `/opt/ui-skill-validation-20261020/`，不作为技能运行依赖。网页检查针对构建后的文件；游戏通过 Pygame 事件队列执行按键、鼠标和合成控制器事件。

控制器检查没有接入实体手柄。移动 App、小程序和其他原生平台已补充对应设计及验收规则，本次没有在这些平台构建或真机测试。[当时的 16 个行为用例](https://github.com/wangshen310-hub/ui-skill/blob/a5eb2ab3157b957bb842065328b8323610c14480/evals/cases.yaml)用于后续维护，尚未完成逐例的独立模型回归；不能把这次 34 项样例检查计作这 16 例全部通过。

安装阶段遇到腾讯云 npm 镜像元数据截断，改用单次命令指定官方 registry；npm 10 的依赖解析错误通过本次样例的 `--legacy-peer-deps` 处理。没有修改服务器的全局 npm 设置。
